Behind the screens. The event id is checked on the server (it must be a published online event with registration open) and the return address is built from it, never taken from the link, so it cannot be used to send people elsewhere. Registration is by email, so a refresh or a double tap never registers twice. Replay visitors at the five minute gate follow the same door and return to the replay.
