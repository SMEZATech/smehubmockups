Specs

Measured from the vector master.

Aspect ratio
2.70 : 1 (900.01 × 333 in the SVG viewBox) — set height and let width follow (h-9 w-auto), never both
Standard size
h-9 (36px tall) in headers and footers — renders 97px wide
Minimum width
120px for the full logo. Below that, use the icon instead
Clear space
At least the width of the small accent bar on all sides — roughly a fifth of the mark's width
Icon aspect
0.87 : 1 (329.8 × 380.7) — slightly taller than square, so it needs w-auto or a square box with place-items-center
Colours
Cube: red #DC183C to wine #592D3A gradient, accent #FF9900. Wordmark: #0C1F31 on light; white + #FF9900 reversed
Format
SVG everywhere in the product. It is smaller than the PNG and stays sharp at any zoom or pixel density

Rules

The ones that actually get broken.

✓ Do
  • Use the reversed file on navy or dark backgrounds — do not just lower the opacity
  • Set height only and let width follow, so the logo never distorts
  • Give it an alt of “SME South Africa” when it is the page logo
  • Use an empty alt="" when the icon is decorative and a text label sits beside it
✗ Don't
  • Don't put a text label next to the full logo — the wordmark is already in the file
  • Don't wrap the reversed logo in a white chip; it is built for dark grounds
  • Don't recolour the cube. Its gradient and orange accent are fixed on every background
  • Don't stretch, rotate, crop, or add shadows and effects
  • Don't use the icon alone on social profiles — those take the full logo
